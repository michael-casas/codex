# Screen recording

Use screen recording to demonstrate temporal behavior, reproduce a bug, or create reviewable evidence. Use screenshots for still state and flows for executable repetition.

Preflight the exact target and recording operation. Current recording support can be platform/tool-version limited, and encoding may require ffmpeg. Start recording immediately before the relevant path, perform only the scoped interactions, stop promptly, and report the saved artifact and limitations.

Never treat video as an executable verdict. Pair it with structural assertions, tests, logs, or other evidence appropriate to the claim. Avoid recording secrets, personal data, notifications, or unrelated applications.

Provenance: curated from Casona `argent-screen-recording`.
