# Escalate from agent-device to Argent

Invoke the global `argent` skill through Executor when the task requires one of these specialist surfaces:

- Hermes/CDP evaluation beyond `agent-device cdp` heap and leak workflows;
- React fiber-tree inspection, render-count queries, source lookup, or combined React/native reports;
- injected UIKit/native hierarchy, view-at-point, or native request capture;
- OCR/font-aware screenshot comparison or Argent-native visual flow assertions;
- Instruments or Perfetto analysis that needs Argent's report/query pipeline;
- Chromium tabs, cookies, local/session storage, or rich CDP state control;
- an existing Argent YAML flow that must be recorded, repaired, or replayed;
- a failure where `agent-device` returned insufficient accessibility, runtime, or profiling evidence.

Before escalation, retain the failing command, session/device identity, observed error, and any useful artifacts. Do not make the Argent pass rediscover avoidable state.

Use `agent-device` for routine interaction, repeatable verification, `.ad` replay suites, Maestro compatibility, and primary evidence collection.
