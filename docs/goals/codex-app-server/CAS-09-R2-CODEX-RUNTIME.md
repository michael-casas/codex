**Model:** `gpt-5.6-sol`, medium reasoning  
**Role:** Base repair owner for production daemon/control/Browser composition

## Objective

Replace every unconfigured production Codex Control executable path with one scoped loopback runtime that connects the accepted task-level MCP gateway and Svelte Browser view to the canonical daemon. A successful delegation or workflow command returns one stable handle plus one complete loopback `browserUrl`; the Browser consumes the accepted projection without direct App Server WSS or database authority.

## Required behavior

- The daemon remains the sole durable state, delivery, retry, and background execution composition root.
- The production control executable injects real scoped services; `CONTROL_NOT_CONFIGURED` is impossible after a healthy startup and remains the truthful result before it.
- One loopback-only surface owns MCP commands, authorization, snapshot/wait, Svelte assets/routes, and complete `browserUrl` presentation.
- Codex callers never receive database credentials, App Server credentials/URLs, host paths, provider method order, or raw secrets.
- Browser clients use one snapshot/wait stream and selected-agent-only detail; cancellation, daemon restart, stale cursor, port conflict, and cleanup fail closed.
- No app-to-app source imports, second daemon, scheduler, retry loop, cache, broker, or public listener.
