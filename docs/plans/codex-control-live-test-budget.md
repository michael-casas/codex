# Codex Control — Founder live test budget

Applies to future provider-backed validation in this campaign. Synthetic tests
and deterministic local checks do not consume model calls and remain preferred.

- Test agents use the GPT-5.6 family and low reasoning where the selected model
  supports it. This records the Founder's phrase “light reasoning” as low;
  do not send an invented light effort value or silently substitute unsupported
  settings.
- Maximum four provider-backed test agents per validation run. Do not evade the
  budget by repeated batches. Choose the smallest representative live check.
- When mixed-effort proof is needed, one Sol-medium and one Luna-high OR
  Terra-high may run together within that cap; remaining agents use low effort.
- No xhigh, max or ultra live testing. Reuse valid captured live evidence;
  run exhaustive failure/parameter matrices with synthetic fixtures.
- Determine whether a fixture uses real authentication and provider inference
  before running it. “Local” or “controlled” does not mean synthetic.
- Do not change frozen test semantics merely to reduce cost. If a standing
  provider-backed suite cannot meet the budget, halt for a scoped test-plan
  amendment rather than running or falsely claiming the suite green.
- Record known launches, effective model/effort and returned usage. Unavailable
  usage/cost is unknown, not zero. A visually unchanged usage meter is not proof
  that inference consumed no tokens.

The implementation worker's model is unchanged. The user-requested landing-page
demo is a separate authorized workload: four Luna-high builders followed by one
Sol-medium judge, at most four simultaneously. Do not downgrade it or launch it
before the existing Base/runtime/presentation gates are satisfied.
